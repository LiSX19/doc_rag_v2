## 四、RAG vs 大模型直接回答对比

| 评估维度 | RAG + 大模型 | 大模型直接回答 |
|---------|-------------|--------------|
| **信息准确性** | ✅ 基于真实考纲/真题，可溯源 | ⚠️ 依赖训练数据，可能有"幻觉" |
| **知识截止日期** | ⚠️ 知识库约2024年，对2026年问题有风险 | ⚠️ 依赖模型训练数据截止日期 |

| **时效性信息** | 🔴 无法回答最新考试动态 | ✅ 如模型训练数据更新，可回答 |
| **推理/规划类问题** | 🟡 有参考材料，但需要LLM综合 | ✅ LLM 擅长综合推理和规划 |
| **覆盖面** | ✅ 覆盖1-6级各维度内容 | ✅ 通用知识广泛 |
| **引文溯源** | ✅ 可以提供具体文件来源 | ❌ 无法提供文档级引用 |

## 五、核心发现与结论

### 5.1 RAG 知识库的优势场景

| 场景 | 示例 | 相似度范围 |
|------|------|-----------|
| 考试结构/评分标准查询 | HSK5合格分180、HSK6写作45分钟 | 0.98-1.00 |
| 词汇量/语法点检索 | HSK3=600词、HSK5=2500词 | 0.96-0.99 |
| 真题答案查找 | H31553B卷听力答案 | 0.94-0.99 |
| 教材结构分析 | HSK标准教程5的6大板块 | 0.93-0.97 |
| 等级对应关系 | HSK四级=B2 | 0.98-0.99 |

### 5.2 RAG 知识库的风险场景

| 场景 | 风险描述 | 风险等级 |
|------|---------|---------|
| 最新年份考试安排 | Q17：知识库无2026年考试日程 | 🔴 高 |
| 改革内容（2026年） | Q16：检索到2009年旧版信息被错误引用 | 🔴 高 |
| 考官主观建议类问题 | Q25、Q29：解题技巧类内容少 | 🟡 中 |
| 全球考点分布 | Q13：无考点清单文档 | 🔴 高 |
| 口语流畅度提升 | Q30：有内容但非系统教学建议 | 🟡 中 |

### 5.3 大模型直接回答的风险

| 问题类型 | 大模型直接回答的风险 |
|---------|-------------------|
| "HSK5多少分通过？" | 可能回答错误（如说200分），RAG可精确定位到180分 |
| "HSK4词汇量多少？" | 可能在1200词附近波动，RAG可精确到1200 |
| "HSK有七级吗？" | 可能混淆新旧版本，RAG可溯源到具体文档 |
| "2026年什么时候考试？" | 大模型和RAG均无法准确回答（需实时查询） |

## 六、建议

### 6.1 RAG 知识库优化建议

1. **补充时效性文档**：增加最新年份的考试安排（chinesetest.cn 爬取）
2. **增加教学策略文档**：解题技巧、备考计划类内容较少
3. **补充 HSK 7-9 级资源**：知识库目前仅覆盖 1-6 级
4. **标注知识截止日期**：在检索结果中提示"此内容截至2024年"

### 6.2 RAG + LLM 混合使用建议

| 问题类型 | 推荐方式 |
|---------|---------|
| 精确数据查询（分数、词汇量、时长） | **RAG 优先** |
| 考试结构/真题答案 | **RAG 优先** |
| 最新动态（2025-2026年） | **RAG + 实时搜索** |
| 备考规划/学习计划 | **RAG 检索参考材料 + LLM 综合** |
| 主观建议/技巧类 | **LLM 直接回答 + RAG 提供背景** |
